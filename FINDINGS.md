# Security and robustness audit

The root Hexo configuration selects the bundled `defaultone` theme. The audit covered the site and theme manifests and lockfiles, configuration, documentation, content, the Hexo database, and local and vendored theme code. Severity reflects repository exposure, including optional features. The credential scan surfaced no suspected committed credentials. The tree contains no CI workflows.

## Verification

The site and theme npm lockfiles passed clean-install dry runs. Local checks exercised inline config serialization, locale fallback, search rendering and retry, quote rendering, the build update check, and encrypted-post handling. Required tarballs were absent from the local npm cache and registry access was unavailable, which prevented full installs, a Hexo build, and a registry-wide dependency audit. Dependency findings cite the advisories used for the targeted review.
